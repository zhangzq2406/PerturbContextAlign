# Current manifest guide

This directory intentionally contains only the current public-facing manifests.

- `RESULT_SOURCE_ANALYSIS_MAP.tsv`: current 34-panel source-to-analysis map.
- `DATASET_NAMING_MAP.tsv`: internal dataset identifiers and manuscript display names.
- `INPUT_AVAILABILITY.tsv`: what is included here versus external/companion data.
- `TABLE_PRODUCER_STATUS.tsv`: current producer/derivation status for the few source tables whose generation lineage requires an explicit note.

Historical maps, release-repair logs, caption-audit archives, old renumbering records, and recovery artifacts are not part of the public GitHub package.
